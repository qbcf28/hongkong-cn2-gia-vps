## CN2 GIA到底是什么，为什么大家抢着买

CN2全称ChinaNet Next Carrying Network，是中国电信搭建的一条独立骨干网，专用于国际数据传输，走的是AS4809这条自治域号。它和普通163骨干网(AS4134)最大的区别在于，163网络承载了绝大部分公网流量，晚高峰拥堵是常态；而CN2走的是专用通道，拥挤程度低很多，延迟也更稳定。

CN2线路里又分两个等级：CN2 GT和CN2 GIA。CN2 GT只是去程或者部分路径走CN2，遇到国际出口拥堵时还是可能绕路；CN2 GIA则要求去程和回程都全程走AS4809，是CN2里等级最高的产品，通常延迟能压到30到60毫秒之间，晚高峰波动也小得多。正因为这个"双程CN2 GIA"的门槛比较高，成本也水涨船高，这也是为什么真正意义上的CN2 GIA服务器价格普遍不便宜。

问题就出在这儿："CN2"这个词经常被商家泛化使用。有些产品只是"去程走CN2"，回程走的其实是别的线路，比如CMI(中国移动国际)；还有些干脆只是普通CN2 GT贴牌成GIA卖。所以搜索"香港CN2 GIA VPS"之前，弄清楚具体商家的线路走向比记住价格更重要。
